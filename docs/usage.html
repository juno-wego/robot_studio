설치 및 검수

Jetson 플래싱

리커버리 USB를 연결하면 상단에 Jetson 모듈이 표시됩니다. 캐리어보드는 실물 표기를 보고 선택합니다.

캐리어보드모듈JetPack
NVIDIA P3768Orin NX / Nano6.2, 6.2.1
NVIDIA P3737AGX Orin6.2.1
NVIDIA P4071Thor T5000 / T40007.2.1
AVerMedia NX215B (D115), D135Orin NX / Nano6.2.1

파일 다운로드 → 플래싱 시작 순서로 진행합니다. NVMe·eMMC 새로 설치는 대상 저장 장치를 지웁니다. 복제 SSD 보존은 NX215B + Orin NX 16GB에서 선택할 수 있습니다.

다른 NVIDIA 보드는 SDK Manager에서 호환 버전을 선택합니다. 제조사 보드는 해당 업체의 BSP, SDK Manager extra config 또는 설치 도구를 사용합니다.

로봇과 센서

Jetson에 인터넷을 연결한 뒤 로봇을 선택합니다. ROS 2 / 로봇 드라이버를 설치하고 필요하면 센서 또는 제조사의 ARM64 .deb를 추가합니다. A2·B2는 Unitree SDK2와 ROS 2 메시지 패키지가 설치됩니다. Ranger Mini·Scout Mini는 제조사 ROS 드라이버가 설치됩니다. Ranger Mini 프리셋은 Humble에서 V1–V3, Jazzy에서 V1–V2를 대상으로 합니다. CAN 포트와 모델별 실행 설정은 제조사 안내를 따릅니다.

유선 센서는 포트 확인에서 실제 포트를 확인하고, 장비 이름과 고정 IPv4를 입력합니다. 설정은 재부팅 후 적용됩니다.

검수

  1. Jetson에서 로봇과 센서 드라이버를 실행합니다.
  2. 검수 탭에 로봇 상태·LiDAR 등 확인할 ROS 토픽과 최소 수신 횟수를 추가합니다.
  3. 수신 검수 시작을 누르고 수신 횟수와 메시지 형식을 확인합니다. 수신 횟수 통과는 토픽 연결 확인 결과입니다.
