SLAM / Navigation

로봇 탭의 SLAM / Navigation에서 SLAM Toolbox와 Nav2를 설치합니다. Ubuntu 22.04는 ROS 2 Humble, Ubuntu 24.04는 Jazzy를 사용합니다.

Go2 지도 생성

Go2 드라이버를 실행하고, 새 터미널에서 같은 ROS 환경을 적용한 뒤 매핑을 실행합니다.

source ~/wego_ws/install/setup.bash
ros2 launch wego bringup.launch.py
source ~/wego_ws/install/setup.bash
ros2 launch "${XDG_DATA_HOME:-$HOME/.local/share}/wego-jetson/go2_navigation/mapping.launch.py"

기본 입력은 /livox/lidar입니다. 다른 점군을 쓰면 cloud_topic:=/토픽을 지정하세요.

ros2 run nav2_map_server map_saver_cli -f ~/map

다른 로봇

2D LiDAR는 LaserScan 토픽을, 3D LiDAR는 2D 변환 결과를 사용합니다. 스캔 프레임과 로봇 기준 프레임의 TF, 오도메트리, 지도 프레임을 확인합니다.

Nav2 주행 전에는 로봇별 footprint, 속도 제한, 컨트롤러, 명령 토픽을 설정하고 실제 주행 검수를 진행합니다. 앱에서 패키지를 설치하는 동안 로봇은 정지 상태로 둡니다.
